Solicitação de exclusão de dados

Você pode solicitar a exclusão dos dados pessoais tratados pela Scandex+ Serviços Digitais, observadas as hipóteses legais de retenção.

Como solicitar

  1. Envie um e-mail para contato@scandexplus.com.br com o assunto Solicitação de exclusão de dados.
  2. Informe seu nome, telefone ou e-mail associado e uma descrição dos dados ou serviço relacionado.
  3. Podemos pedir confirmação de identidade para impedir exclusões indevidas.

Prazo e retenções obrigatórias

Confirmaremos o recebimento e responderemos dentro do prazo legal aplicável. Dados necessários ao cumprimento de obrigação legal, exercício de direitos, prevenção a fraudes, segurança ou auditoria contratual poderão ser preservados de forma restrita pelo período exigido.

Dados do WhatsApp

Para excluir a conversa no seu aparelho, use os recursos do próprio WhatsApp. Para solicitar a exclusão dos registros mantidos pela Scandex+, siga o procedimento acima.
